A familiar tool, a new opportunity

What is GitHub—and why might IDs use it?

Usually for developers

An online home for project files, revisions, and collaboration.

Useful for instructional designers, too

Vibe coding makes custom course interactives easier to create. GitHub gives those projects a place to live, change, and be shared.

So when AI helps us build an interactive, what happens next?

The course-development challenge

AI makes custom course interactives easier. What happens next?

Where does it live? Who updates it next semester? What happens when the course is copied? What changed six months ago? Who inherits it?

A useful division of responsibility

The LMS is where students experience it.
GitHub is where the project lives.

That is the problem we are going to use GitHub to help solve today.
