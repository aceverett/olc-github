Five words are enough to begin

GitHub is an online project folder with a memory.

Repository
The project folder stored online.
Fork
Your own safe copy of that folder.
Editor
The browser workspace where you make changes.
Commit
A named save point you can return to.
Pages
The feature that turns your project into a webpage.

Why this workflow matters

Your design idea should not stop at the edge of the LMS editor.

LMS editor

Reliable, but limited

Useful interaction ideas can collapse into static text and long pages.

Authoring suite

Capable, but heavy

Licenses and packaged exports can make small changes costly or slow.

GitHub + AI

Flexible and reachable

A browser-based workspace makes small, testable webpages easier to build and revise.

You already design, test, revise, and document. GitHub gives those habits a safe project history.

Two Canvas delivery options

Paste the accordion itself—or embed the hosted page.

Option A / direct paste

Use the accordion builder’s HTML

Select Copy Canvas-ready HTML, then paste it into Canvas’s HTML editor. No iframe is needed.

Option B / hosted page

Embed your GitHub Pages URL

Replace YOUR_GITHUB_PAGES_URL in the example, then paste the iframe into Canvas’s HTML editor.

<iframe
  src="YOUR_GITHUB_PAGES_URL"
  title="Interactive course content"
  style="width:100%; min-height:650px; border:0;"
  loading="lazy">
</iframe>

Pages setup: Settings → Pages → Deploy from a branch → main → /(root). Free accounts publish Pages from public repositories; private-repository publishing requires a supported paid or organizational plan. Follow your institution’s Canvas embedding policy.
